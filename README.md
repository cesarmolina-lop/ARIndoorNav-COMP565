# ARIndoorNav-COMP565
An AR Indoor Navigation proof-of-work for COMP565 using Unity + AR Foundation for use on iOS.

## Deliverables (PoC)
- AR Foundation session on iPhone
- Tap-to-place anchored cube
- Hardcoded path visualization (LineRenderer)
- Simple A* proof in editor (non-AR)

## Repo Structure
- /Docs: reports and planning docs
- /Media: demo videos and screenshots
